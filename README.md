# Aether Music

Local-first Android music player with **Liquid Glass** UI, **Media3** playback, Room library, playlists, equalizer UI, stats, and a home-screen widget shell.

## Build

```bash
# Desktop
./gradlew :app:assembleDebug

# Or GitHub Actions workflow "Build Aether APK"
```

## First run

1. Install APK  
2. Grant **music / storage** permission  
3. Tap **Scan library**  
4. Play from Home / Library  

## Stack

Kotlin · Jetpack Compose · Media3 · Room · DataStore · Coil · Glance/RemoteViews widget

## Privacy

Audio files stay on device. No upload of your library.
